|---|---|---|

| shake | `Board.svelte` (scoped) | `@keyframes shake` (translateX ±2~6px), `.shake { animation: shake 0.4s }`, 거부된 행. scoped 스타일 |

## 1. 원칙과 토큰

### 원칙

1. 개인 모드의 모션 언어를 계승한다. **pop(입력·등장 강조) / shake(거부) / drop(등장) / fade(전환)** 네 가지를 바탕으로 한다. 개인 쪽과 이름이 겹치지 않게 `mp-` 접두어를 붙여 복제한 키프레임과, 재촉 알림 등 멀티에만 있는 파생 키프레임이 있다(§5 표). 회전은 재접속 스피너(`mp-spin`)에만 쓴다.
2. 모션은 정보를 더하지 않으면 넣지 않는다. 한 화면에서 동시에 움직이는 요소는 2개 이하.
3. 서버는 연출 시간을 모른다. 규칙은 즉시 반영하고 연출은 클라이언트만 한다 (설계 §4, TASKS의 서버 무연출 원칙과 일치).

### 시간 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--mo-fast` | 100ms | 버튼·토글 피드백 |
| `--mo-pop` | 150ms | pop |
| `--mo-fade` | 200ms | fade |
| `--mo-drop` | 300ms | drop |
| `--mo-shake` | 400ms | shake |
| (토큰 아님) 돌림판 | 1500ms | JS 상수 `WHEEL_MS`(`CoopPicker.svelte`). `--mo-wheel` CSS 토큰은 만들지 않았다 |
| (토큰 아님) 스태거 | 90ms 배수 | `.d1`~`.d5` 클래스의 `animation-delay`(90·180·270·360·450ms) |

CSS 토큰은 `mp.css`의 `.mp`에 선언한 위 다섯 개(`--mo-fast/pop/fade/drop/shake`)뿐이다.

이징: 등장 `ease-out`, 퇴장 `ease-in`, 그 외 키워드 그대로 (개인과 동일).

## 4. reduced-motion 대체 (요약)

`prefers-reduced-motion: reduce`일 때: 이동·스케일·회전을 제거하고 즉시 전환한다. 구현(`mp.css` 끝의 미디어 쿼리)은 `.mp` 아래 모든 animation·transition 시간을 0.01ms로 덮어써 사실상 즉시이며, 100ms fade는 따로 두지 않았다. shake만 테두리 깜빡임(`mp-dflash` 300ms)으로 바꾼다. **피드백은 사라지면 안 된다.**

| 모션 | 대체 |
|---|---|
| shake | 테두리 색 `--danger` 300ms 1회 깜빡임 |
| 돌림판 | 결과 즉시 강조 + "돌림판 결과: ○○" 문구 |
| 재접속 스피너 | "재접속 중…" 정적 문구 |
| 유예 진행 바·pulse | 숫자만 |
| pop·drop·크로스페이드 | 즉시 또는 opacity 100ms |

JS 연출(돌림판·재촉 레이어)은 `matchMedia`로 같은 조건을 읽는다. 개인 코드에는 손대지 않는다 (개인은 지금처럼 모션 그대로).

## 5. 구현 메모

- 위치: 공통 키프레임은 `src/lib/components/mp/mp.css`(`.mp` 아래로 한정), 특정 화면 전용은 해당 컴포넌트의 scoped 스타일. 내 칸 입력 pop은 `app.css` 전역의 `.cell-animation`을 재사용하고, 내 보드의 shake는 `Board.svelte` 것을 그대로 쓴다.
- 토큰 선언: `mp.css`의 `.mp`에 `--mo-*` 다섯 개를 선언한다. 전역 `app.css`는 건드리지 않는다.
- 멀티 쪽 키프레임(개인 쪽과 이름이 겹치지 않게 `mp-` 접두어):

| 키프레임 | 정의 | 쓰는 곳 |

  화면 흔들림·전체 플래시는 CSS 키프레임이 아니라 `NudgeLayer`의 Web Animations API(`animate()` 500ms)로 낸다.
- 돌림판 step 배열: `[60, 60, 70, 80, 100, 130, 170, 220, 300, 400]` (ms, 합 1590). JS 타이머로 구동하고 `WHEEL_MS` 1500ms에 맞춰 비율로 줄이며, 서버가 정한 항목에서 끝나도록 거꾸로 센다. 멈춘 뒤 700ms(`SETTLE_MS`) 읽을 시간을 둔 다음 보드에 행이 들어간다.
- 재촉 알림 (2026-11-01 사용자 결정, 이전의 "토스트 + 참가자 카드 종 아이콘 흔들림"은 폐기): 수신 쪽(방장) 레이어는 `--scrim` 배경에 뒤 화면 blur 2px. 가운데 종 아이콘 4rem(±30° 600ms 주기 반복, 뒤에 `--btn-primary` 링 2겹이 1초 주기로 퍼짐), 문구 1.5rem 굵게 "{이름}님이 재촉합니다!"(여럿이면 "{이름}님 외 n명이 재촉합니다!"), 그 아래 "n명 중 m명 준비"(m은 2rem, `--sel-bg` 칩. n·m은 접속 중인 방장 외 인원 기준), 상자 오른쪽 위 `재촉 n회` 배지(`--danger`), 버튼 "지금 시작"(시작 조건 미달이면 "대기실 보기")과 "닫기"(각 56px). 레이어가 뜰 때와 그 뒤 4초마다 화면 흔들림(±12px 500ms), 전체 플래시(`--btn-primary` 0.25, 3회), 알림음(660·880·1175Hz 세 음, 각 120ms), 진동([200,100,200]). 탭 제목은 "(!) 재촉 - …"로 500ms 깜빡이고 포커스가 돌아오면 복원한다. 자동으로 닫히지 않고 버튼·Esc로만 닫힌다. 방장이 레이어 안 버튼을 누르면 반복 연출이 멈춘다. 닫은 뒤에는 시작 버튼 옆 `재촉 n회` 배지(`--danger`)와 시작 버튼 1초 주기 글로우가 남고, 시작하거나 설정을 바꾸면 사라진다. 알림음은 설정 "재촉 소리" 스위치로 끈다. 이 값은 `prefs.svelte.ts`가 세션 동안만 들고 있고 저장하지 않는다(새로고침하면 켬). reduced-motion이면 레이어·블러·흔들림·플래시·펄스 없이 상단 고정 배너(전체 폭, 56px, 같은 문구 + "n명 중 m명 준비" + 같은 버튼 2개)만 쓰고, 소리·탭 제목·배지는 유지한다. 송신 쪽(참가자)은 버튼 "재촉" 그대로, 토스트 "재촉했습니다", 자기 화면 상단 배너 0.8초 미리보기("상대 화면에 이렇게 뜹니다"), 쿨다운 30초 유지.
- 테스트 불가 항목 (수동 확인): 모션의 체감 시간, reduced-motion 대체, 돌림판 수신 지연 차이, 크로스페이드 중 깜빡임. `pnpm preview` 2창으로 본다.
